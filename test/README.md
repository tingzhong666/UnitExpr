# 单元表达式测试套件

## 概述
本测试套件包含60个测试用例，覆盖了单元表达式库的所有核心功能。

## 测试分类

### 1. 基础数值运算测试（12个用例）
- 基本算术运算：加减乘除
- 浮点数运算
- 复杂算术运算（优先级、括号）
- 负数运算

### 2. 单位运算测试（12个用例）
- 基本单位运算
- 单位转换
- 复合单位运算
- 单位抵消

### 3. 函数测试（12个用例）
- 三角函数（支持角度单位）
- 反三角函数
- 指数和对数函数
- 其他数学函数（sqrt, abs, max, min）

### 4. 组合表达式测试（12个用例）
- 物理公式测试
- 工程公式测试
- 复杂数学表达式
- 实际应用场景

### 5. 错误处理测试（12个用例）
- 单位不匹配错误
- 数学错误（除以零、负数平方根等）
- 语法错误
- 语义错误

## 构建和运行

### Windows环境
1. 确保已安装Visual Studio 2022
2. 运行构建脚本：
   ```
   build_test.bat
   ```
3. 运行测试：
   ```
   build\bin\Release\unit_expr_tests.exe
   ```

### 手动构建
```bash
mkdir build
cd build
cmake .. -G "Visual Studio 17 2022" -A x64
cmake --build . --config Release
```

## 测试框架
测试使用简单的自定义框架，包含：
- `TestRunner`类：管理测试用例和运行测试
- `TestCase`结构：定义单个测试用例
- 模块化测试注册：每个测试类别在单独的文件中

## 扩展测试
要添加新测试，请：
1. 在相应的测试文件中添加测试用例
2. 或创建新的测试文件并注册到`main.cpp`中

## 预期输出
测试运行时会显示：
- 每个测试的名称和表达式
- 测试结果（✅通过/❌失败）
- 详细的结果比较
- 最终统计信息
