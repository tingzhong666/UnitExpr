
## 更新计划
### 项目概述
- **目标**：C++14库，支持字符串表达式解析、量纲计算（基于exprtk + LLNL/Units）。
- **环境**：MSVC2022_amd64，指定CMake路径。
- **测试**：60个用例（36基础 + 24组合/错误），手动验证。
- **核心功能**：表达式解析、单位支持、运算/函数注册、自动单位抵消。

### 实施步骤（优先级：高→低）
1. **环境搭建**（高优先）
   - 创建CMakeLists.txt，配置C++14、MSVC工具链、包含includes/路径、链接libs/units.lib。
   - 验证编译：空项目构建（cmake生成+构建）。

2. **核心解析器**（高优先）
   - 集成exprtk基础表达式求值（包含exprtk.hpp）。
   - 引入LLNL/Units：单位类型（如m/s, kg）、运算符重载（使用units头文件+lib）。
   - 实现量纲包装器：数值+单位，结果自动单位计算/抵消。

3. **功能扩展**（中优先）
   - 注册运算符（+ - * / ^等，支持单位）。
   - 注册函数（sin/cos/log/exp/max/min等，支持角度单位如deg）。
   - 支持变量（运行时绑定，如x=2kg）。
   - 无限嵌套括号处理。

4. **测试实现**（高优先）
   - 创建test/目录，编写手动测试代码（独立main函数或脚本），覆盖60个用例（匹配PRD列表）。
     - 基础：数值、运算符、函数、变量。
     - 组合：如sin(30deg)*2m/s + cos(45deg)*km/h；PV=nRT。
     - 错误：单位不匹配抛异常。
   - 手动运行验证：编译执行，比较输出与预期（无框架）。

5. **验证&优化**（中优先）
   - 手动运行所有测试，确保100%通过。
   - 性能测试：复杂表达式基准（手动计时）。
   - 文档：README.md示例、API说明。

### 风险&依赖
- Units与exprtk兼容：需自定义适配器（包装exprtk符号表支持单位类型）。
- Windows特定：确认MSVC链接.lib无误。
- 测试覆盖：手动验证需仔细记录结果；优先实现PRD指定用例。
